# 🖨️ Servicio de Impresión - La Hidrocálida

**Impresión automática de tickets para el sistema POS de La Hidrocálida**

## 🚀 Inicio Rápido

```batch
# 1. Instalar
cd print_service
install.bat

# 2. Iniciar servicio
start_service.bat

# 3. ¡Listo! Los tickets se imprimen automáticamente
```

## 📋 ¿Qué hace este sistema?

- ✅ **Imprime automáticamente** cuando se solicita la cuenta
- ✅ **Formato profesional** para restaurante
- ✅ **Compatible** con impresora Easytime SP-POS891ED
- ✅ **Sistema robusto** con cola y reintentos

## 📁 Estructura

```
print_service/          # Servicio de impresión completo
├── config/            # Configuración
├── core/              # Lógica principal
├── server/            # Servidores API/WebSocket
├── scripts/           # Scripts de instalación y control
└── logs/              # Logs y cola de impresión
```
